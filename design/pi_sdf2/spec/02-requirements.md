# 需求

## 概述

pi_sdf 是自研的有符号距离场（SDF）矢量图形库。现状存在内存安全问题、若干确定性缺陷、内部 API 边界混乱，以及 native 与 wasm 两套并行实现。本设计在 pi_sdf2 中重构该库：保持 SDF 生成能力等价，使内部模块边界清晰、对外接口在两个平台统一，提升健壮性，且不牺牲时间与空间复杂度。

## 目标

| 目标 | 成功指标 |
|---|---|
| 功能等价 | 轮廓 / 近邻弧 / SDF 纹理三项结果与 pi_sdf 0.1.34 在约定容差内一致 |
| 结构清晰 | 算法层零 unsafe、零平台条件编译；模块依赖单向无环 |
| 双版本适配 | Windows / Android / wasm32 三目标编译通过，核心链路接口一致 |
| 健壮 | 不可信输入不 panic / trap；4 项确认缺陷全部消除 |
| 性能不退化 | 同机同输入的端到端耗时与峰值内存 ≤ 基线 100% |

## 需求项

### REQ-001 功能等价

- 描述：pi_sdf2 提供与 pi_sdf 等价的字形轮廓提取、近邻弧网格计算、SDF 纹理生成能力。
- **来源**：用户原话（“重构”、硬性要求不牺牲复杂度与效果）
- 验收标准：
  - REQ-001.1 WHEN 对同一字体同一字符提取轮廓，系统 SHALL 返回与 pi_sdf 端点数量一致、端点坐标误差 ≤ 1/1024 单位的轮廓
  - REQ-001.2 WHEN 对同一轮廓以相同 tex_size 与 pxrange 计算近邻弧，系统 SHALL 返回与 pi_sdf 相同的单元划分与弧索引集合
  - REQ-001.3 WHEN 对同一轮廓以相同 tex_size 与 pxrange 生成 SDF 纹理，系统 SHALL 返回与 pi_sdf 逐像素差 ≤ ±1 灰度的纹理
  - REQ-001.4 WHEN 对同一 SVG 路径以相同 tex_size 与 pxrange 生成 SDF 纹理，系统 SHALL 返回与 pi_sdf 逐像素差 ≤ ±1 灰度的纹理
- 关联 NFR：NFR-001、NFR-002

### REQ-002 统一接口同时适配 native 与 wasm

- 描述：同一套对外接口在 native 与 wasm 两目标上均可用，且不再为同一功能维护两份并行等价实现。
- **来源**：用户原话（“接口应当适配 native 和 wasm 两个版本”）
- 验收标准：
  - REQ-002.1 WHEN 在 native 目标编译，系统 SHALL 暴露核心链路（字体 → 轮廓 → 近邻弧 → SDF 纹理）的完整接口
  - REQ-002.2 WHEN 在 wasm32 目标编译，系统 SHALL 暴露同一核心链路的接口
  - REQ-002.3 IF 某行为在 native 与 wasm 上由签名不同或逻辑重复的方法提供，THEN 系统 SHALL NOT 保留该重复
- 关联 NFR：NFR-003、NFR-004

### REQ-003 模块边界清晰且可机械验证

- 描述：内部每个模块的职责与依赖方向明确；平台相关代码与算法代码分离，边界可由静态检查判定。
- **来源**：用户原话（“把内部模块的 api 解构的更清晰”）
- 验收标准：
  - REQ-003.1 WHEN 对算法层源码执行检索，系统 SHALL 不含平台条件编译、不含 unsafe
  - REQ-003.2 WHEN 检查任一内部模块的依赖，系统 SHALL 满足单向且无环
  - REQ-003.3 IF 一个源文件承担多于一个职责，THEN 系统 SHALL 按职责拆分
- 关联 NFR：NFR-004

### REQ-004 不可信输入不导致崩溃

- 描述：来自库外的字节与参数不合法时，对外接口返回错误而非 panic / trap。
- **来源**：用户原话（“算法优化跟健壮”）+ **本次推断**（具体输入类别由调研得出）
- 验收标准：
  - REQ-004.1 IF 传入的 wasm 边界字节无法解析，THEN 系统 SHALL 返回错误，且 wasm 模块不 trap
  - REQ-004.2 IF 传入的字体字节非法或损坏，THEN 系统 SHALL 返回错误
  - REQ-004.3 IF 传入的参数越界（如 tex_size 为 0），THEN 系统 SHALL 返回错误而不进入 panic 路径
- 关联 NFR：NFR-002

### REQ-005 已确认缺陷修复

- 描述：消除调研中确认的 4 项行为缺陷。
- **来源**：**本次推断**（从源码调研提取，用户以“健壮”授权）
- 验收标准：
  - REQ-005.1 WHEN 构建近邻弧网格，系统 SHALL NOT 进入无终止的纹理填充循环
  - REQ-005.2 WHEN 判定大圆弧（曲率参数绝对值大于 1）是否包含某点，系统 SHALL 与圆弧几何定义一致
  - REQ-005.3 WHEN 反转轮廓方向，系统 SHALL 使反转作用于实际结果而非临时副本
  - REQ-005.4 WHEN 从弧列表计算 SDF，系统 SHALL 返回符号正确的距离
- 关联 NFR：NFR-001

### REQ-006 wasm 调试链路可用

- 描述：修复并保留用于调试本库 SDF 的 wasm 导出，使 JS 可调用并获得轮廓 / 近邻弧 / SDF 数据。
- **来源**：用户原话（“这个是用来调试本库的 sdf 的，你可以将其修复”）
- 验收标准：
  - REQ-006.1 WHEN JS 调用调试接口并传入字体与字符，系统 SHALL 返回可展示的轮廓、近邻弧与 SDF 数据
- 关联 NFR：NFR-003

## 非功能需求

### NFR-001 性能不退化

- 描述：重构后运行时性能与内存占用不劣于 pi_sdf 0.1.34。
- 指标：同机、同输入（同一字体与字符集、同一 tex_size）下，端到端耗时 ≤ 基线 100%，峰值内存 ≤ 基线 100%；时间复杂度与空间复杂度不升。
- 验证方式：基准测试，记录基线与重构后数值对比。
- 挡在哪条选型上：ADR-002（索引 arena 的常数时间共享）、ADR-005（依赖精简）

### NFR-002 内存安全

- 描述：全库不存在未定义行为；算法层零 unsafe。
- 指标：算法层源码检索不到 unsafe；不存在裸指针跨所有权、transmute 构造非法值；wasm 与 native 目标下均无未定义行为。
- 验证方式：静态检索 + 代码审查 + 测试。
- 挡在哪条选型上：ADR-002（以索引替代裸指针）、ADR-006（错误返回取代 panic）

### NFR-003 平台覆盖

- 描述：三个目标均可编译。
- 指标：Windows（x86_64-pc-windows-msvc）、Android（aarch64-linux-android 或等价 NDK 目标）、wasm32-unknown-unknown 三目标编译成功。
- 验证方式：逐目标构建。
- 挡在哪条选型上：ADR-001（单 crate 三层分层）、ADR-004（stable 工具链）

### NFR-004 边界可机械验证

- 描述：模块边界可由脚本检查，不依赖人工判断。
- 指标：算法层源码检索不到平台条件编译与 unsafe；每个模块依赖方向单向无环。
- 验证方式：脚本检索 + 依赖图检查。
- 挡在哪条选型上：ADR-001（核心层与平台层分离）

## Non-Goals

| 不做什么 | 为什么不做 |
|---|---|
| 不迁移 blur（模糊 / 外发光 / 阴影） | 本轮范围外，用户本轮选择排除 |
| 不迁移 svg.rs | 该模块当前为死代码（构造时忽略入参），用户本轮选择排除 |
| 不支持 Linux / macOS | 用户本轮选择的 native 目标为 Windows + Android |
| 不改变 SDF 的语义与渲染效果 | 与 REQ-001 等价验收冲突；本轮只做等价 + 健壮 + 结构 |
| 不引入 GPU 渲染管线 | 本库只负责生成 SDF 数据，渲染由调用方负责 |
| 不追求 bit-exact 输出 | 会锁死浮点运算顺序，与“算法优化”目标矛盾 |
| 不保证旧接口 100% 向后兼容 | 用户口径：默认不改，但与结构合理性 / 性能权衡后收益显著时允许破坏 |

## 需要你确认的默认

| 项 | 采用的默认 | 为什么这么定 | 用户可否决 |
|---|---|---|---|
| 兼容性承诺 | 默认保持老 Rust 与老 JS 调用可用；当改动对结构清晰或性能的收益显著时允许破坏，破坏点逐条列出 | 用户口径“尽量不改，收益不错就改” | 可 |
| 等价容差 | 逐像素 ±1 灰度；端点坐标 ≤ 1/1024 单位；近邻弧网格划分一致 | 量化舍入客观存在；bit-exact 禁止优化 | 已确认 |
| 崩溃策略 | 对外入口返回错误；内部不变量 debug 断言，release 不静默返回错值 | 热路径 panic 会崩宿主进程 | 已确认 |
| 缺陷修复范围 | 4 项确认缺陷 + 全部 panic 驱动流程改为错误返回 | 与“健壮”硬要求一致 | 已确认 |
| 性能基线 | 同机同输入，耗时与内存均不劣化（≤ 100%） | 用户要求“一致或更好” | 已确认 |
| 范围边界 | blur 与 svg 不迁移；纯注释死示例删除 | 用户本轮选择 | 可 |
| wasm 分配器 | 保留 talc 静态分配器，容量可调 | 现状做法，改动无收益 | 可 |
| wasm 导出命名 | 允许规整重命名 | 老 JS 调用方本已损坏，收益大于成本 | 可 |
