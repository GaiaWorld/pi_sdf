# 共享数据结构

跨模块共享的纯数据类型（不含行为）。字段级约束可被 D7b 投影为代码注释。

### API-001 ArcEndpoint 弧端点

- 模块：跨模块共享（定义于 MOD-002，被 MOD-003 / MOD-004 / MOD-005 / MOD-006 / MOD-007 / MOD-008 / MOD-009 引用）
- 对应需求：REQ-001.1、REQ-002.3
- 签名：

  ```
  pub struct ArcEndpoint {
      pub p: [f32; 2],      // 端点坐标，有限值
      pub d: f32,           // 曲率参数 = tan(圆心角/4)，有限值；0 表示线段
      pub tag: Option<u64>, // 线段共享键，仅线段使用；其余为 None
  }
  ```

- requires：p、d 均为有限值；调用方不得传入 NaN / Inf
- ensures：可无损转换为弧（参见 API-008）；tag 仅作去重用途，不影响几何
- 错误模式：无（纯数据，构造不失败）
- 顺序约束：无
- 性能：无

#### 用例

| ID | 关联 | 前置 | 动作 | 期望 |
|---|---|---|---|---|
| CASE-001 | REQ-001.1 | 一端点含合法 p、d | 转换为弧再转回端点 | p、d 与输入逐位一致 |
| CASE-002 | REQ-002.3 | 同一批端点 | 分别经 native 与 wasm 路径编解码 | 两侧端点集合一致 |

**被引用于：** MOD-002、MOD-003、MOD-004、MOD-005、MOD-006、MOD-007、MOD-008、MOD-009

## 依赖方向约束

共享类型是被多个模块 import 的唯一合法形式，仅限**数据类型，不含行为**。与 D6「冻结对可互相 import」不冲突：后者管模块内部，本条管模块之间。CI 检查时两条都要放行，其余方向照常禁止。
